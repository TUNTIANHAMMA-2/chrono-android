# CHRONO v1.0.0 — 首个正式发行版

**CHRONO** 是一款原生 Android（API 33–37）离线周期事项提醒与硬件级生物识别加密卡包应用。

## 核心亮点

### 1. 品牌与导航焕新 (`CHRONO`)
- 全新 **CHRONO** 双色几何矢量品牌标识（双层卡片 + $45^\circ$ 计时斜切口 + 琥珀圆点 `#D97706`），自动适配浅色与深色/AMOLED 主题背景对比度；
- 统一 6 字母底部导航标签（**`Expiry`** / **`Wallet`** / **`Config`**）与专属定制矢量图标；
- 配备 Android 13+ 自适应桌面图标（含 Material You 单色主题图标层）。

### 2. `Expiry` — 周期与到期事项
- 实时分钟级生命周期进度条（`已过 XX%`）与语义化状态色；
- 四大状态分区（已到期 / 即将到期 / 进行中 / 已暂停）与分类胶囊筛选；
- 一键按月/按年顺延续期、暂停/恢复提醒、WorkManager 每日后台检查与锁屏敏感名称隐藏。

### 3. `Wallet` — 硬件级加密卡包与 120Hz 3D 拟真交互
- **StrongBox / TEE 硬件级密钥保护**：卡片敏感载荷采用 `AES-256-GCM` 独立 IV 加密存储，支持生物识别/锁屏凭据就地解锁并自动执行查看或复制；
- **120Hz 3D 卡片物理引擎**：
  - $\pm 25^\circ$ 手势意图分类器（水平顺滑切卡、斜向/纵向无界 360° 跟手阻尼翻面）；
  - `5%` 真实圆角与 `3.0dp` 10 层 3D 投影后屏幕空间立体斜切厚度；
  - 陀螺仪/重力实时视差高光、预烘焙硬件平铺磨砂微粒纹理、莫奈动态取色卡背及三大卡组织（银联天坛 / 万事达双地球 / Visa 飞鸽）全息防伪徽标；
- **离线 BIN 识别与卡面系统**：内置离线压缩 BIN 库，支持本地相册导入卡面与可选自建卡面聚合服务。

### 4. `Config` — 莫奈主题引擎与隐私安全
- **OKLab 莫奈主题面板**：支持 `跟随系统 / 浅色 / 深色`、**AMOLED 纯黑模式**、11 款微缩主题预览卡与自定义色相/饱和度种子取色器；
- **防截屏与最近任务遮罩（`FLAG_SECURE`）**：默认开启，支持在 `Config` 页实时开关；
- **Argon2id + AES-256-GCM 离线加密备份**：支持通过系统 SAF 跨机导出与原子恢复。

- 最低系统要求：**Android 13（API 33）** 及以上；
- 下载附件中的 APK 安装包即可直接安装使用（完全离线运行，无需联网或注册账号）。
